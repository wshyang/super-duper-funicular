# Live n-way comparison and feature-parity ledger

**Goal: feature parity across every branch that implements this product, without sacrificing
local strengths.** This document is the authoritative comparison. It is *live*: the hash table is
regenerated by a command, and the narrative is appended every turn. It is not a scoreboard — a
capability counts only when its **acceptance** holds.

Authoritative for the in-app view: `src/shared/parity.ts` (the matrix rendered in the Parity tab).
A discipline test fails the build if a capability here is missing there, or if the branch list here
drifts from `src/generated/branch-tips.json`.

switches branch, never touches a peer, and has no background watcher.

## 4. What each implementation does well

**Sprite Motion Lab** — deepest art pipeline: 17 independently articulated photographic plates,
semicircular rounded-end cutting, two-segment rolling shoe in raster *and* SVG, a raster→SVG
vectoriser with hierarchical rig stitching, and the most complete image-prompt provenance log
including regeneration justifications. **Cost:** the most complex build, and its photographic seams
are documented as unresolved.

**Stride Lab** — strongest *verification* culture: Playwright with video on by default, walking
profiles proven against a running-only model first, interactive bone-local cut calibration with
registered PNG/JSON export, and a Python extraction toolchain with byte/pixel hash inventories.
**Cost:** the photographic shoe is rigid, so contact roll is a support-pivot approximation.

**Funicular** — most disciplined *material* model: one coherent studio plate with a registered
arm-free torso replacement, colour-class mattes as a hard invariant (purge + compatible refill),
membrane-filled ball joints, measured far/near width parity, plus the best machine-readable
cross-branch tooling (`branches:compare` writing tips + history). **Cost:** no hands, no pelvis,
no ponytail, run-only.

**Procedural Runner** — smallest, cleanest seed: the most literal GREENFIELD split, a pure
procedural React engine with React 19 and no native image stack, and the shortest path from clone
to running. **Cost:** fewest capabilities and no learning/ledger discipline.

**Ours** — the only implementation whose *discipline* is n-way (all five branches, in-app matrix,
gate-checked sync), whose pipeline grid detection is pixel-derived rather than hard-coded, and
whose rendering is assertable in Node without a browser or native canvas. **Cost:** art depth is
the shallowest of the five; six explicit Gaps.

## 7. How to keep this document honest

1. Run `npm run branches:compare`; commit the regenerated JSON and table.
2. If a hash moved, inspect the diff in `/tmp` **before** changing any cell from `?`/`Partial`.
3. Change `src/shared/parity.ts` in the same commit as this table; the gate enforces it.
4. Append a progress-history bullet. Never rewrite an earlier bullet.
5. When a peer catches up, delete the exclusivity claim. When we fall behind, say so.
