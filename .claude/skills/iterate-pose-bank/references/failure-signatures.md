# Known Failure Signatures and Their Fixes

Match every rejected candidate against this table before writing the next prompt.
Observed frequencies are from Calls #73–#95 of the Athletic pilot.

| # | Signature (how it shows up in audit + pixels) | Root cause | Proven fix |
|---|---|---|---|
| S1 | **Generic-sprint attractor**: pass/down phase renders as extended stride or high-knee sprint; audit: `shoe separation > 190px`, `swing foot lifted > 175px`, or grounded shoe fails toe/flat contact-width. Hit #76, #79, #80, #82, #85. | Target pose is far from the model prior; skeleton guides are suggestions and get ignored | Template A delta edit on the nearest photo candidate (≤3 named joint corrections). If it recurs twice, change the guide geometry itself; never add adjectives |
| S2 | **Ghosted airborne shoe**: newly airborne/tucked footwear renders washed-out, semi-transparent, pink-tinted. Hit #91, #93 (2 of 2 calls that newly lifted a shoe). Audit symptom varies with spill severity: severe spill detaches the shoe as a 2–3k px island (`locate_islands.py` names it); milder spill passes the automated gates entirely — quantitative pink-cast fractions were measured at 27% ghosted vs 22% clean, too close to gate on. **Detection is therefore visual: always view a zoomed crop of every newly airborne shoe/sock before accepting** (this is how both hits were actually caught). | Diffusion blends small high-contrast objects into the surrounding key color | Template B repaint-only call ("Do not move any limb"); fixed first-try 2/2 (#92, #94) |
| S3 | **Float-off**: whole figure airborne when the phase requires contact; audit: silhouette bottom outside ground band [baseline−45, baseline+10]. Hit #91. | Pose edit re-centers the figure vertically | Add one clause to the next call: lower the figure so the named shoe bears weight (#92) |
| S4 | **Wardrobe flip**: an accessory changes color/material (wristband rendered black). Hit #84, #85. | Edits re-sample loosely-constrained details | Enumerate every flip-prone item verbatim in all prompts ("both wristbands stay sky-blue"); re-check in every review; refine with Template B if flipped |
| S5 | **Soft contact shadow / background gradient**: audit `shade_px` in the thousands but hue stays in key family. Hit nearly every call. | Generator refuses "no shadow" absolutely | Not a rejection. `audit_pose_bank.py --normalize` flattens it (≤53 px residual halo). Reject only if contamination leaves the key hue family or detaches islands |
| S6 | **Geometry passes, pose still wrong** (G4 PASS, G5 FAIL): e.g. swing knee far above guide height with compliant foot landmarks. Hit #82. | Silhouette metrics cannot see interior joints | Mandatory eyeball comparison against the solved guide on every candidate; name the residual joint error as the next delta |
| S7 | **Duplicate pose**: new candidate ~identical to an existing frame; audit: cross-bank IoU ≥ 0.90. Hit #85 (vs X02). | Same attractor as S1 | Reject regardless of prompt wording; switch base plate or guide geometry. Note: counterpart pairs (φ vs φ+0.5) legitimately reach ~0.89 |
| S8 | **Normalizer eats subject**: pink-lit fabric/skin sheen repainted flat (magenta speckles inside the singlet). Hit once during tooling bring-up. | Hue-band background classification leaking through antialias channels | Fixed in-auditor (border-connected flood + 2 px erode/redilate guard). Still visually diff one normalized plate per batch; recalibrate if it recurs |
| S9 | **Identity drift** across edit chains (face/build shifts subtly). Risk, not yet observed ≤2 edits deep. | Copy-of-copy conditioning | Cap chains at ~2–3 edits; judge G1 against the H00 master, never the edit base; if drifted, rebase the delta onto an earlier plate |
| S10 | **Near/far chirality unprovable**: no pixel evidence of which limb is camera-near. Permanent in strict profile. | Lateral projection genuinely ambiguous | Do not claim it. Encode depth cues at generation time (occlusion order, "subtly less lit"), record as caveat, resolve at part-harvest via cross-frame consistency |
