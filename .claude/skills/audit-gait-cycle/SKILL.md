# Audit gait cycle

After changing gait, IK, paint, or cutouts:

1. Sample at least 32 phases, not only 8 canonical frames.
2. Check: both feet plant, crossover exists, flight exists, no unilateral lock, lean stays forward.
3. Write findings into FDS; do not treat passing unit tests as seam certification.
4. Keep raster dumps under `reports/` (gitignored).
